# Проверка шаринга в мини-приложении MAX

Статическая страница из одного файла: вызывает `window.WebApp.shareMaxContent(...)` из [MAX Bridge](https://dev.max.ru/docs/webapps/bridge) и показывает, что получилось. Серверной части нет, запросов к сторонним сервисам нет, кроме загрузки `https://st.max.ru/js/max-web-app.js`.

Страница открывается внутри MAX как мини-приложение чат-бота. Вне MAX она показывает «WebApp есть: нет».
